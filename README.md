# Calibration-Free Cross-Subject Motor-Imagery BCI with Online Euclidean Alignment on a Zynq-7020 FPGA

Code, hardware sources and measured results for the paper

> R. Janapati *et al.*, "Calibration-free cross-subject motor-imagery decoding with online Euclidean alignment in hardware on a low-cost Zynq-7020 FPGA," *submitted*, 2026.

A new user can operate the MI-BCI **without a calibration session**: an online Euclidean-alignment (EA) unit in programmable logic whitens each EEG trial from unlabeled trials only (recursive reference, trace normalization with a leading-one detector + Newton, coupled Newton–Schulz inverse square root — multiply/add/shift only, fixed latency), followed by an int8 EEGNet-type decoder (2,420 parameters).

| Result (PYNQ-Z2, XC7Z020) | 50 MHz | 75 MHz (76.92 MHz actual) |
|---|---|---|
| Latency per 4-s trial | 3.59 ms | 2.34 ms |
| Speed-up vs. ARM Cortex-A9 (21.37 ms) | 5.96× | 9.13× |
| Energy per trial (ARM: 3.33 mJ) | 0.57 mJ | 0.77 mJ |
| Resources | 63% LUT, 77% DSP, 21% BRAM, Fmax 80.9 MHz | |

Accuracy (calibration-free, online EA): BCI IV-2a LOSO 51.82% (4-class) / 73.19% (2-class); PhysioNet (104 subjects, subject-exclusive 5-fold) 44.26% / 72.30%.

## Datasets (public, not redistributed here)

| Dataset | Link | Used as |
|---|---|---|
| BCI Competition IV, dataset 2a (9 subjects, 22 ch, 4 classes) | https://www.bbci.de/competition/iv/ — also BNCI Horizon 2020 "001-2014": https://bnci-horizon-2020.eu/database/data-sets | LOSO evaluation, FPGA board test (subject S1) |
| PhysioNet EEG Motor Movement/Imagery (109 subjects, 64 ch) | https://physionet.org/content/eegmmidb/1.0.0/ (DOI: 10.13026/C28G6P) | second dataset, 104 subjects, 22 matched channels |

Both are downloaded automatically through [MOABB](https://moabb.neurotechx.com/) (`BNCI2014_001`, `PhysionetMI`) on the first run (`python/data.py`, data cached in `~/mne_data`).

## Repository layout

```
python/      training and evaluation (PyTorch + MOABB)
  data.py            dataset loading, causal 4–40 Hz band-pass (2 biquads), decimation to 125 Hz
  ea.py              offline EA and the online EA algorithm used in hardware
  model.py           EEGNet-type decoder, parameter / MAC counters
  approx.py          base-2 piecewise-linear ELU used in training and hardware
  train_loso.py      leave-one-subject-out calibration-free evaluation (+ ablation flags)
  pretrain.py        PhysioNet pretraining / subject-exclusive 5-fold evaluation
  deploy.py          BN folding, spatial–temporal reordering, int8 simulation, HLS header export
  analyze_online_ea.py  warm-up curve and sensitivity to k, K, epsilon
  export_board_data.py  test data for the board (subject S1, int32 Q.10)
  aggregate.py, parse_log.py, plot_*.py   tables, statistics, figures
notebooks/   Kaggle/Colab notebooks that ran all experiments (hanet_kaggle_v4.ipynb = final)
hls/         Vivado HLS 2019.2 sources: online_ea.cpp, hanet_cnn.cpp, mi_bci_top.cpp (top),
             test benches, run_hls.tcl (C-sim + synthesis + IP export), run_cosim.tcl (C/RTL co-sim),
             export_S1/ (int8 weights and constants generated by deploy.py)
vivado/      build_pynq_z2.tcl (block design, implementation, bitstream mi_bci.bit + mi_bci.hwh)
pynq/        board scripts: mi_bci_board.py (accuracy/latency), cpu_baseline.c/.py (ARM baseline),
             power_test.py (idle/FPGA/CPU phases for the power meter), diag_board.py
results/     logs, per-subject CSV tables, online-EA analysis, Vivado/HLS reports
             (z2_* = serial first version, z2_v5_* = final parallel version)
figures/     figures of the paper
```

## Reproducing

**1. Accuracy experiments** (GPU recommended; Kaggle/Colab notebooks in `notebooks/`)
```bash
pip install -r requirements.txt
cd python
python train_loso.py --dataset 2a --out runs/2a --no-attention --K1 64 --P1 4 --P2 8 --act elu --dg none
python deploy.py --ckpt runs/2a/hanet_target1.pt --dataset 2a --target 1 --hls-dir ../hls/export_S1
```

**2. Hardware** (Vivado HLS + Vivado 2019.2, part xc7z020clg400-1)
```bash
cd hls && vivado_hls -f run_hls.tcl          # C simulation, synthesis, IP export
cd ../vivado && vivado -mode batch -source build_pynq_z2.tcl   # -> mi_bci.bit, mi_bci.hwh
```

**3. Board** (PYNQ-Z2, PYNQ image v3.x; copy `mi_bci.bit`, `mi_bci.hwh`, `board_S1.npz`, `pynq/*`, `hls/export_S1/` to one folder)
```python
%run mi_bci_board.py     # accuracy and latency (set FCLK_MHZ = 50.0 or 75.0)
%run cpu_baseline.py     # ARM Cortex-A9 baseline
%run power_test.py       # read the inline USB power meter in each phase
```
`board_S1.npz` is produced by `python/export_board_data.py` (or cell 3 of `hanet_kaggle_v4.ipynb`) from the IV-2a data.

## Known issue

The C models of the serial and the parallel accelerator are bit-identical on all 576 trials of S1, and the serial version reproduces the int8 model exactly on the board (72.57%). The parallel (final) bitstream gives 71.18% on the board (90.3% class agreement); `hls/run_cosim.tcl` localizes the difference by exact C/RTL co-simulation of the alignment and decoder halves. Latency and power are not affected.
